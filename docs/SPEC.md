# SPEC.md — 太陽系シミュレーター

## 1. 目的

ブラウザ上で動作する簡易太陽系シミュレーターを、ハーネスエンジニアリングの手法（仕様→実装→テスト→公開の一周）で構築する。学習上のゴールは「物理ロジックと描画を分離し、決定的な純粋関数として軌道計算をテストできる構成」を体得すること。最終成果物は Vercel に静的デプロイされ、URL で共有できる。

本シミュレーターは科学計算ツールではなく、**可視化優先のスケールモデル**である。距離・サイズ・時間はいずれも見栄えのために圧縮・加速される。この前提を全設計の基礎とする。

## 2. v1 スコープ（今回作るもの）

### 2.1 シーン構成
- 太陽（中心、自発光マテリアル）
- 8惑星（水星・金星・地球・火星・木星・土星・天王星・海王星）
- 各惑星の**円軌道**を表す軌道線（リング）
- 星空背景（drei の `Stars`）

### 2.2 軌道モデル
- 軌道は**真円**とする（楕円・離心率は v2）。
- 各惑星は実データに基づく軌道半径（AU）と公転周期（地球年）を持つ。
- 惑星の角位置は時刻 t の純粋関数 `position(planet, t)` で一意に決まる。
- 公転面は黄道面（y=0 平面）に統一する。軌道傾斜角は v2。

### 2.3 スケーリング（必須の設計判断）
- **距離**: AU をそのまま使うと内惑星が密集し外惑星が画面外に飛ぶため、圧縮関数を適用する（既定は平方根ベースの圧縮。`scale.ts` に集約し差し替え可能にする）。
- **半径**: 実半径は太陽と惑星で桁が違うため、対数的に圧縮し、かつ最小可視サイズを保証する。
- **時間**: 実時間では何も動かないため加速する。スライダーは「シミュレーション内経過年数」を制御する。

### 2.4 自転
- 各惑星は自軸まわりに自転する（見栄え用、簡易でよい）。自転軸の傾きは v1 では省略可（v2 で厳密化）。

### 2.5 操作 UI
- **時間スライダー**: シミュレーション時刻 t（年）を 0〜数十年で操作。
- **再生 / 一時停止**トグルと、速度（倍率）切り替え。
- **カメラ操作**: drei の `OrbitControls`（回転・ズーム・パン）。
- 惑星名の簡易表示（ラベルは drei `Html` か固定オーバーレイ。凝らなくてよい）。

### 2.6 非機能要件
- Vercel Hobby 枠で完結（静的、外部API・サーバ常駐なし）。
- 初回ロード後はネットワーク不要で動作。
- デスクトップの一般的な GPU で 60fps を目安（重い後処理は v2）。

## 3. v2 以降（やらないが、拡張余地として明記）

先取り実装しないこと。設計はこれらを**妨げない**程度に配慮する。

- 楕円軌道（ケプラー方程式の数値解、離心率）
- 主要な衛星（月・ガリレオ衛星・タイタン等）
- postprocessing の **Bloom**（太陽の発光を映えさせる）
- 軌道傾斜角・自転軸傾斜の厳密化
- 惑星クリックでカメラフォーカス＋情報パネル
- 土星の環、テクスチャマッピング

## 4. データ要件

各惑星について最低限以下を静的定義する（実値ベース、出典は README に記載）:

- `id`, `name`（日本語表示名）
- `semiMajorAxisAU`: 軌道長半径（AU）— v1 では円軌道半径として使用
- `orbitalPeriodYears`: 公転周期（地球年）
- `radiusKm`: 赤道半径（km）
- `color`: 既定マテリアル色（テクスチャ導入までのプレースホルダ）
- `rotationPeriodHours`: 自転周期（自転速度の算出用、符号で逆行を表現）
- `axialTiltDeg`: 自転軸傾斜（v1 では保持のみ、描画反映は任意）

## 5. 受け入れ条件（Acceptance Criteria）

v1 完成と見なす条件:

1. 8惑星と太陽が表示され、再生すると各々が異なる速度で公転する（内側ほど速い）。
2. 時間スライダーを動かすと全惑星の位置が時刻に応じて連続的に変化する。
3. 同じ t に戻すと全惑星が同じ位置に戻る（決定性が目視で確認できる）。
4. `OrbitControls` で自由に視点を変えられる。
5. `docs/TEST_SPEC.md` のドメイン層テストが全パスする。
6. `npm run build` が成功し、Vercel にデプロイして公開URLで動作する。

## 6. 明示的な非目標

- 重力多体シミュレーション（惑星間相互作用）は行わない。各惑星は独立に固定軌道を回る。
- 実時刻・実天文位置との一致は求めない（位相の初期値は任意でよい）。
- モバイル最適化は v1 の対象外（動けばよい）。
